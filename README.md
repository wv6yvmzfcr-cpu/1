# منصة إيدولينك — EduLink MY

منصة تربط الطلاب العرب ومنطقة آسيا الوسطى بمعاهد اللغة الإنجليزية في
ماليزيا: تطبيق **Expo/React Native** + قاعدة **Supabase** (PostgreSQL،
Auth، Storage، Edge Functions)، بمحتوى متعدد اللغات (JSONB) ولوحة تحكم ويب.

## 🚀 التشغيل من الصفر
اتبع الدليل الكامل: **[`docs/التشغيل-من-الصفر.md`](docs/التشغيل-من-الصفر.md)**
(قاعدة البيانات → لوحة التحكم → الدوال → التطبيق).

## محتويات المستودع
```
admin/                لوحة تحكم ويب كاملة (صفحة مستقلة HTML/JS)
app/  src/            تطبيق Expo: الشاشات، المكوّنات، hooks، i18n، المكتبات
supabase/*.sql        مخطط قاعدة البيانات (نفّذ ١..٩ بالترتيب)
supabase/functions/   دوال الحافة + طبقة تفويض _shared
scripts/              توليد صفحات SEO الثابتة
docs/                 المراجعة ودليل التشغيل
```

## أُنجز في هذا العمل
- ✅ **لوحة تحكم ويب كاملة** (`admin/`) — تحكّم كامل بالموقع، مع رفع صور،
  تصدير CSV، وإرسال إشعارات Push. مُختبرة في المتصفح.
- ✅ **إصلاحات أمنية حرجة** (`supabase/٩`) — إغلاق تسريب بيانات الطلاب عبر
  الـViews، منع الطالب من ترقية نفسه، **إصلاح تكرار RLS لا نهائي** كان
  سيعطّل التطبيق، وحماية السجلات المالية. مُختبرة على PostgreSQL 16 (6
  اختبارات أمنية نجحت).
- ✅ **إصلاح تفويض دوال الحافة** — `partner-deliver` و`doc-review` كانتا
  تعملان بلا تحقق من الصلاحية؛ وُحّد التفويض في `_shared/auth.ts`.
- ✅ **إصلاح أخطاء ترتيب SQL** — التسلسل ١..٩ يُطبَّق الآن نظيفاً على قاعدة
  جديدة.
- ✅ **تجميع المشروع كاملاً** في المستودع جاهزاً للنشر.

التفاصيل الكاملة في **[`docs/مراجعة-الكود.md`](docs/مراجعة-الكود.md)**.
