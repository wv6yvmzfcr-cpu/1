# منصة إيدولينك — EduLink MY

منصة تربط الطلاب العرب ومنطقة آسيا الوسطى بمعاهد اللغة الإنجليزية في
ماليزيا (تطبيق Expo/React Native + قاعدة Supabase).

يحتوي هذا المستودع على:

- **`admin/`** — 🆕 لوحة تحكم ويب كاملة للتحكم في الموقع (صفحة مستقلة
  HTML/JS). راجع [`admin/README.md`](admin/README.md).
- **`supabase/`** — مخطط قاعدة البيانات (نفّذ الملفات بالترتيب `١`→`٨`).
  الملف **`٨- سياسات لوحة التحكم.sql`** جديد ويصلح أخطاء ويضيف صلاحيات
  المدير الضرورية للوحة.
- **`docs/مراجعة-الكود.md`** — 🆕 مراجعة الكود والأخطاء المكتشفة وما تم بناؤه.

## البدء السريع
1. نفّذ ملفات `supabase/` بالترتيب في Supabase SQL Editor.
2. رقِّ بريدك كمدير (انظر `admin/README.md`).
3. افتح `admin/index.html` وسجّل الدخول.
