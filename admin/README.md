# لوحة تحكم إيدولينك — EduLink Admin

لوحة تحكم ويب كاملة للتحكم في منصة إيدولينك: المعاهد، الإعلانات،
الطلبات ومستنداتها، الشركاء والعمولات، المحتوى متعدد اللغات، والإعدادات.

صفحة **ثابتة مستقلة** (HTML/JS فقط) تتصل بمشروع Supabase مباشرةً من
المتصفح باستخدام **مفتاح `anon` العام** — لا خادم وسيط، ولا كشف لأي
مفتاح سري.

---

## خطوات التشغيل (مرة واحدة)

### 1) نفّذ ملفات SQL بالترتيب
من لوحة Supabase → **SQL Editor**، نفّذ ملفات `supabase/` بالترتيب من
`١` إلى `٩`. الملف **`٩- إصلاحات حرجة.sql`** ضروري — بدونه لن تستطيع
اللوحة التعديل (يضيف صلاحيات المدير عبر RLS) كما يغلق ثغرات أمنية حرجة.

### 2) رقِّ حسابك كمدير
أنشئ حساباً في تطبيقك (أو من Supabase → Authentication → Add user)،
ثم في SQL Editor:

```sql
insert into public.admin_users (user_id)
select id from auth.users where email = 'بريدك@example.com'
on conflict (user_id) do nothing;
```

للتأكد:
```sql
select u.email from public.admin_users a join auth.users u on u.id = a.user_id;
```

### 3) افتح اللوحة
افتح `admin/index.html` مباشرةً في المتصفح، أو ارفع مجلد `admin/`
لأي استضافة ثابتة (Vercel / Netlify / GitHub Pages / Cloudflare Pages).
كل الملفات نسبية، فتعمل من أي مسار.

في صفحة الدخول أدخل:
- **رابط المشروع:** `https://xxxx.supabase.co` (Project Settings → API → Project URL)
- **مفتاح anon العام:** (Project Settings → API → `anon` `public`)
- **البريد وكلمة المرور** لحسابك المُرقّى كمدير.

تُحفظ بيانات الاتصال محلياً في المتصفح (`localStorage`) فلا تُدخلها كل مرة.

---

## الأمان

- المفتاح المستخدم هو **`anon` العام فقط** — آمن للاستخدام في المتصفح.
- كل الصلاحيات تُفرَض على مستوى قاعدة البيانات عبر `row level security`
  ودالة `is_admin()`. أي مستخدم غير مُرقّى (حتى لو عرف المفتاح) **لا
  يستطيع** التعديل — RLS يمنعه.
- ⚠️ **لا تستخدم مفتاح `service_role` هنا** — لا حاجة له، وكشفه في
  المتصفح خطر أمني.
- لعرض ملفات المستندات (bucket خاص) تُنشئ اللوحة روابط موقّعة مؤقتة
  (Signed URLs) صالحة ساعة واحدة.

---

## البنية

```
admin/
├── index.html   ← الواجهة والتنسيق
├── schema.js    ← تعريف الجداول والحقول (عدّل هنا لإضافة جدول/حقل)
└── app.js       ← المحرك: دخول، صلاحيات، CRUD، التقارير
```

### كيف أضيف حقلاً أو جدولاً؟
كل شيء مُعرَّف في `schema.js`. لإضافة حقل لمعهد مثلاً، أضِف سطراً في
مصفوفة `fields` داخل `institutes`. الأنواع المدعومة:
`text, textarea, number, bool, date, datetime, i18n, i18n_list,
string_array, json, select, relation`. المحرك يبني النموذج والقائمة
تلقائياً — لا حاجة لكتابة HTML.

## استكشاف الأخطاء

| المشكلة | الحل |
|--------|------|
| «هذا الحساب ليس مديراً» | نفّذ خطوة الترقية (2) وتأكد من ملف ٩ |
| لا تظهر بيانات / خطأ صلاحية عند الحفظ | لم يُنفَّذ ملف ٩، أو الحساب غير مُرقّى |
| فشل الاتصال / صفحة فارغة | تحقق من الرابط والمفتاح، وأن للموقع وصول شبكة لـ Supabase |
| «column price_verified does not exist» | نفّذ ملف ٩ (يضيف العمود) |
