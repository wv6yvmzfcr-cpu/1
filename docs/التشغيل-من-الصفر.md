# 🚀 تشغيل منصة إيدولينك من الصفر (A → Z)

دليل عملي كامل. المشروع كله جاهز في المستودع؛ أنت تنفّذ الأوامر بمفاتيحك.

المشروع 3 أجزاء مستقلة، كل واحد يعمل وحده:
1. **قاعدة البيانات** (Supabase) — الأساس، ابدأ بها.
2. **لوحة التحكم** (`admin/`) — صفحة ويب، تشتغل فوراً بعد القاعدة.
3. **تطبيق الجوال** (Expo) + **دوال الحافة** (اختياري بعدها).

---

## المتطلبات
- حساب **Supabase** مجاني (تسجيل الدخول عبر GitHub يكفي).
- لتطبيق الجوال والدوال: **Node.js 18+** و **Supabase CLI** و **Git**.
- (للمزايا الذكية) مفتاح **Anthropic API**.

---

## 1) قاعدة البيانات ⭐ (ابدأ هنا)

1. أنشئ مشروعاً جديداً في [supabase.com](https://supabase.com) (اختر أقرب Region + كلمة مرور قاعدة قوية).
2. من **SQL Editor** نفّذ ملفات مجلد `supabase/` **بالترتيب**، كل ملف لحاله:

   | # | الملف | يفعل |
   |---|------|------|
   | ١ | الجداول الأساسية | اللغات، المعاهد، الطلبات، RLS |
   | ٢ | الأتمتة والمتطلبات | خط السير، المستندات، المساعد |
   | ٣ | بطاقة الوصول MDAC | إجراء الوصول الموقوت |
   | ٤ | الشركاء والعمولات | الشركاء، الموافقات، العمولات |
   | ٥ | بيانات المعاهد | بيانات المعاهد الحقيقية |
   | ٦ | الأسعار | نظام التسعير وقفل السعر |
   | ٧ | نظام SEO والمدونة | الكلمات، الصفحات، المدونة |
   | ٩ | **إصلاحات حرجة** | أمان + صلاحيات المدير + إصلاحات |

   > ⚠️ **الترتيب مهم** — كل ملف يبني على سابقه. الملفات ١..٧ **تُنفَّذ مرة
   > واحدة** على قاعدة جديدة (فيها بيانات أولية، إعادة تشغيلها تعطي خطأ
   > تكرار — طبيعي). الملف **٩ آمن لإعادة التشغيل**.
   > (لا يوجد ملف ٨ — دُمج في ٩.)

3. **رقِّ حسابك مديراً:** أنشئ حساباً (`Authentication → Users → Add user`)، ثم في SQL Editor:
   ```sql
   insert into public.admin_users (user_id)
   select id from auth.users where email = 'بريدك@example.com'
   on conflict (user_id) do nothing;
   ```

✅ **تم اختبار التسلسل ١..٩ كاملاً على PostgreSQL 16** — يُطبَّق نظيفاً
(26 جدولاً، 8 عروض، 60 سياسة)، و**اجتاز 6 اختبارات أمنية سلوكية**.

## 2) لوحة التحكم (تشتغل فوراً)

من `Project Settings → API` انسخ **Project URL** ومفتاح **anon public**.

- **محلياً:** افتح `admin/index.html` في المتصفح مباشرةً.
- **أو انشرها** (مجاناً) على أي استضافة ثابتة:
  ```bash
  # مثال Vercel: من داخل مجلد admin/
  npx vercel deploy --prod
  ```

سجّل الدخول بالرابط + مفتاح anon + بريدك وكلمة مرورك. خلاص — تحكّم كامل.
(تفاصيل أكثر في [`admin/README.md`](../admin/README.md).)

## 3) دوال الحافة (Edge Functions) — للمزايا الذكية

```bash
npm i -g supabase
supabase login
supabase link --project-ref <PROJECT_REF>   # من رابط مشروعك

# انشر كل الدوال
supabase functions deploy assistant doc-review photo-passport \
  partner-deliver seo-generate push-broadcast

# الأسرار
supabase secrets set ANTHROPIC_API_KEY=sk-ant-...
supabase secrets set EDULINK_INVOKE_SECRET="$(openssl rand -hex 32)"
supabase secrets set REMOVEBG_API_KEY=xxx      # لمعالجة الصورة الشخصية
```

⚠️ **مهم للأمان:** أضف إعدادات `verify_jwt` من
[`supabase/functions/README.md`](../supabase/functions/README.md) إلى
`supabase/config.toml` — خصوصاً `partner-deliver`.

## 4) تطبيق الجوال (Expo)

```bash
npm install
```
ثم ضع مفاتيحك في `app.json` تحت `expo.extra`:
```json
"extra": {
  "supabaseUrl": "https://<PROJECT>.supabase.co",
  "supabaseAnonKey": "<ANON_KEY>"
}
```
ثم:
```bash
npx expo start          # امسح QR بتطبيق Expo Go على جوالك
# أو للويب:
npm run build:web
```

> ملاحظة صدق: كود التطبيق أُعيد بناؤه بالكامل من نسخة المشروع الموثّقة
> (تطابقت أعداد الأسطر 100%)، لكن لم أتمكّن من تنفيذ بناء Expo كامل في
> بيئتي (يحتاج تثبيت الحزم). نفّذ `npm install` ثم `npx expo start`
> وستظهر أي تبعية ناقصة إن وُجدت.

## خريطة سريعة
```
admin/                  لوحة التحكم (ويب)
app/  src/              تطبيق Expo (شاشات، مكوّنات، hooks، i18n)
supabase/*.sql          مخطط قاعدة البيانات (١..٩)
supabase/functions/     دوال الحافة (+ طبقة تفويض _shared)
scripts/build-seo.mjs   توليد صفحات SEO الثابتة
docs/                   المراجعة وهذا الدليل
```

## استكشاف الأخطاء
| المشكلة | الحل |
|--------|------|
| «column ... does not exist» أثناء SQL | نفّذت ملفاً خارج الترتيب — ابدأ من ١ على قاعدة نظيفة |
| «duplicate key» عند إعادة تشغيل ١..٧ | طبيعي — هذه ملفات تهيئة تُنفَّذ مرة واحدة |
| اللوحة: «هذا الحساب ليس مديراً» | نفّذ خطوة ترقية المدير (قسم ١-٣) |
| اللوحة: خطأ صلاحية عند الحفظ | لم يُنفَّذ ملف ٩ |
| التطبيق: شاشة بيضاء | تأكد من `supabaseUrl`/`supabaseAnonKey` في `app.json` |
