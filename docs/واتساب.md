# إشعارات ودعم واتساب

واتساب أنسب من إشعارات المتصفح لهذه المنصّة (بوابة ويب + جمهور خليجي).
النظام يستخدم **رقم واتساب واحد** لأمرين:

1. **الدعم (الطالب يراسلك):** جاهز الآن، مجاني، بلا أي إعداد تقني.
2. **الإشعار التلقائي (النظام يرسل عند تغيّر الحالة):** يحتاج WhatsApp Cloud API.

---

## 1) الدعم — تفعيل فوري (خطوة واحدة)

اضبط رقم الدعم في إعدادات التطبيق. من **لوحة التحكم → ⚙️ إعدادات التطبيق**
أضف مفتاحاً:
- **key:** `support`
- **value:** `{"whatsapp": "9665xxxxxxxx"}`  (صيغة دولية بلا +)

أو عبر SQL Editor:
```sql
insert into public.app_config (key, value)
values ('support', '{"whatsapp":"9665xxxxxxxx"}')
on conflict (key) do update set value = excluded.value;
```

بعدها يظهر في بوابة الطلاب: زر **🟢 الدعم** في الأعلى، وزر «تواصل مع الدعم»
في صفحة المتابعة، ورابط «دعم بشري» داخل المساعد الذكي — كلها تفتح واتساب على رقمك.

كما تلتقط البوابة **رقم واتساب الطالب** عند التقديم (يُحفظ في ملفه) لتصله الإشعارات.

---

## 2) الإشعار التلقائي عند تغيّر الحالة (WhatsApp Cloud API)

### ما تحتاجه من Meta (مجاني الإنشاء، برسوم بسيطة لكل رسالة)
1. حساب **Meta Business** + تطبيق WhatsApp في [developers.facebook.com](https://developers.facebook.com).
2. رقم واتساب أعمال، ومنه تأخذ: **Phone Number ID** و **Permanent Access Token**.
3. **قالب رسالة معتمد** (Message Template) — مطلوب للرسائل التلقائية خارج نافذة
   24 ساعة. أنشئ قالباً باسم `app_status` بمتغيّرين في النص:
   > تحديث طلبك في **{{1}}** — المرحلة الآن: **{{2}}**.

### النشر والأسرار
```bash
supabase functions deploy whatsapp-notify
supabase secrets set EDULINK_INVOKE_SECRET="$(openssl rand -hex 32)"
supabase secrets set WHATSAPP_TOKEN="<Permanent token>"
supabase secrets set WHATSAPP_PHONE_ID="<Phone number ID>"
supabase secrets set WHATSAPP_TEMPLATE="app_status"
supabase secrets set WHATSAPP_TEMPLATE_LANG="ar"
```

### ربط التشغيل التلقائي (Database Webhook)
Supabase → **Database → Webhooks → Create**:
- **Table:** `applications` — **Events:** `Update`
- **Type:** HTTP Request → **POST** إلى دالة `whatsapp-notify`
  (`https://<project>.supabase.co/functions/v1/whatsapp-notify`)
- **HTTP Headers:** أضف
  `X-EduLink-Invoke: <نفس قيمة EDULINK_INVOKE_SECRET>`

بعدها: كل تغيير لحالة الطلب (من لوحة التحكم) يُرسل للطالب رسالة واتساب
بعنوان المرحلة الجديدة بلغته — تلقائياً.

### كيف تعمل الدالة
- تتحقق من السرّ الداخلي (لا يستطيع غريب استدعاءها).
- تتجاهل التحديث إن لم تتغيّر الحالة، أو إن لم يكن للطالب رقم.
- ترسل قالباً معتمداً إن ضبطته، وإلا رسالة نصية (تصل فقط ضمن نافذة 24 ساعة).

## ملخص
| الميزة | الحالة | يحتاج |
|--------|--------|-------|
| زر الدعم (واتساب) | ✅ فوري | ضبط `support` في الإعدادات |
| التقاط رقم الطالب | ✅ فوري | لا شيء |
| إشعار تلقائي عند تغيّر الحالة | ⚙️ جاهز | إعداد Meta + Webhook (أعلاه) |
