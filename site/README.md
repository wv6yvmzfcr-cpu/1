# بوابة الطلاب (Web) — إيدولينك

واجهة الطلاب كصفحة ويب (وليست تطبيق جوال): يتصفّح الطالب المعاهد،
يسجّل، يقدّم على معهد، يرفع مستنداته، ويتابع طلبه خطوة بخطوة. تتصل
مباشرةً بـ Supabase بمفتاح `anon` العام (الحماية عبر RLS).

```
site/
├── index.html   ← الواجهة والتنسيق
├── config.js    ← ضع رابط مشروعك ومفتاح anon (خطوة واحدة)
└── app.js       ← منطق البوابة (تصفّح، تسجيل، تقديم، متابعة)
```

## الإعداد (مرة واحدة)

### 1) عبّئ `config.js`
افتح `site/config.js` وضع القيمتين:
```js
window.EDULINK_CONFIG = {
  url: "https://hvotupiqtlnlxfnaiyhm.supabase.co",   // Project URL
  anonKey: "eyJ..."                                   // anon public key
};
```
(الرابط ومفتاح anon من Supabase → Project Settings → API.)

### 2) فعّل الدخول السلس (مهم)
لتسجيل الطلاب فوراً بلا تأكيد بريد:
Supabase → **Authentication** → **Providers** → **Email** → أوقف
**Confirm email**. (إن أبقيته مفعّلاً، سيُطلب من الطالب تفعيل بريده قبل الدخول.)

## المعاينة والنشر
- **معاينة محلية:** بعد تعبئة `config.js`، افتح `index.html` في المتصفح.
- **النشر للطلاب** (مجاناً) — يحتاج رابطاً عاماً:
  ```bash
  # من داخل مجلد site/
  npx vercel deploy --prod       # أو Netlify / Cloudflare Pages / GitHub Pages
  ```
  ثم شارك الرابط مع الطلاب.

## ما الذي يقدر الطالب يسويه؟
- 🏫 تصفّح المعاهد مع فلترة بالمدينة والسعر، وعرض التفاصيل.
- 🏠 تصفّح السكن والتواصل عبر واتساب.
- 👤 تسجيل حساب / دخول، وتعديل ملفه الشخصي.
- 📝 التقديم على معهد (اختيار الأسابيع وشهر البدء).
- 📤 رفع المستندات المطلوبة لكل طلب.
- 🧭 متابعة مراحل الطلب الثمانية + «المطلوب منك الآن» + أسباب الرفض وطريقة الإصلاح + سجل الأحداث.
- 🌍 تبديل اللغة (عربي/إنجليزي) وعرض السعر بعملته.

## الأمان
مفتاح `anon` آمن للنشر في المتصفح؛ كل طالب يرى ويعدّل بياناته فقط عبر
سياسات RLS. **لا تضع مفتاح `service_role` هنا إطلاقاً.**

## ملاحظة
هذه بوابة مبنية بنفس أسلوب لوحة التحكم (HTML/JS يتصل بـ Supabase). إن
رغبت لاحقاً بنسخة تطبيق جوال، مشروع Expo موجود في `app/` و`src/`.
