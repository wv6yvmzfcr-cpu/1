# شعار الموقع (اللوقو)

اللوقو الرسمي مُستخرَج من ملف `EduLink_Logo.pdf` ومقصوص لصيغتين جاهزتين:

- **`logo.jpg`** — الأيقونة فقط (تظهر في شريط التنقّل والتذييل).
- **`edulink-full.jpg`** — اللوقو الكامل (أيقونة + كلمة EduLink) — تظهر في نافذة الدخول.

خلفية الملفات فاتحة (`#fafafa`) فتظهر على «بلاطة» فاتحة نظيفة في الواجهة.

## لو أردت تحديث اللوقو لاحقاً
استبدل الملفين بنفس الاسمين (يُفضّل نفس النِسَب تقريباً). لو توفّرت نسخة **SVG**
شفافة فهي أفضل — أضِفها وغيّر المسارات في:
- `site/index.html` (ابحث عن `/assets/logo.jpg`)
- `site/app.js` (ابحث عن `/assets/edulink-full.jpg`)

> الواجهة كلها مبنية حول ألوان اللوقو: أزرق عميق `#0f5c86` + تركوازي `#15a8a0` + ذهبي رملي `#c9992e`.
