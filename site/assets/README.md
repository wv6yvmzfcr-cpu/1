# شعار الموقع (اللوقو)

ضع ملف اللوقو الرسمي هنا باسم **`logo.png`** (أو الأفضل `logo.svg` إن توفّر):

```
site/assets/logo.png
```

- يظهر تلقائياً في: شريط التنقّل (Navbar)، تذييل الصفحة (Footer)، ونافذة الدخول.
- يُفضّل نسخة **الأيقونة فقط** (مربّعة، بخلفية شفافة) بمقاس ≥ 256×256 لتظهر بوضوح.
- ما دام الملف غير موجود، يظهر شعار بديل أنيق مؤقّت (لا يكسر الموقع).
- لا تغيّر ألوان اللوقو أو نِسَبه — الواجهة مبنية حول ألوانه (أزرق عميق + تركوازي + ذهبي رملي).

> إن أضفت `logo.svg` بدل `logo.png`، غيّر مسار الصورة في `site/index.html`
> (ابحث عن `/assets/logo.png`) إلى `/assets/logo.svg`.
