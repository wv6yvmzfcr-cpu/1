# شعار الموقع (اللوقو)

**`logo.svg`** — شعار إيدولينك (Vector نظيف، حادّ في أي مقاس، بخلفية شفافة).
مرسوم بنفس فكرة الهوية: حلقة/رابط + قبعة تخرّج + طائر أبو قرن + نخلة، بألوان
أزرق عميق `#0f5c86` + تركوازي `#15a8a0` + ذهبي رملي `#c9992e`.

يُستخدم تلقائياً في:
- شريط التنقّل (Navbar) والتذييل (Footer).
- علامة مائية شفافة داخل البنرات (Hero) — بيضاء وخفيفة.
- أعلى نافذة الدخول.

## تعديل اللوقو
كل الرسم داخل `logo.svg` (مسارات SVG قابلة للتحرير). لتغيير مقاسه في الواجهة،
عدّل الأصناف في `site/index.html` (`.logo .mark`, `.hero-mark`, `.modal-logo`).
لا حاجة لأي ملفات صور نقطية — الشعار كلّه Vector.
